# MEDISMART

Aplikasi rekam medis klinik untuk Windows: pasien, antrean, pemeriksaan SOAP, resep dan farmasi, kasir, serta
laporan, dengan satu database utama yang dipakai bersama oleh komputer lain di jaringan klinik.

Unduh versi terbaru di halaman [Releases](https://github.com/tomyoktavian/medismart-rilis/releases/latest).
